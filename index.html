Control de Versiones: Git

¿Qué es Git?

Sistema de Control de Versiones Distribuido

Git es una herramienta fundamental para el desarrollo de software colaborativo. Permite llevar un registro de todos los cambios realizados en el código fuente de un proyecto a lo largo del tiempo.


Comandos básicos que utilizo:

  • git init - Inicializa un nuevo repositorio.
  • git add . - Prepara los archivos para guardar.
  • git commit -m - Guarda un punto de restauración.
  • git status - Muestra el estado de los archivos.

Plataforma: GitHub

¿Qué es GitHub?

Plataforma en la Nube para Código

GitHub es un servicio que permite alojar proyectos usando Git. Es como una red social para programadores, facilitando el trabajo en equipo desde cualquier parte del mundo.


Ventajas de utilizarlo en el Taller:

  • Respaldos automáticos en la nube (git push).
  • Gestión de ramas y colaboración sin pisar código.
  • Portafolio demostrable para futuros trabajos.
